# Studio icons

`aws/` contains 64 px service SVGs and 48 px VPC resource SVGs from the official [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/), release **July 31, 2026**. DynamoDB and RDS use Studio's blue background (`#3B82F6`); their white service artwork is unchanged.

Source package: https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip

AWS permits these assets in architecture diagrams. AWS names and icons belong to Amazon Web Services. Preserve the service artwork and Studio's documented color choices when updating the subset.

`generic/` uses Lucide icons (ISC license, see `LICENSE` there). These describe framework concepts, without assigning them an AWS service. All icons are served locally; the studio makes no runtime requests to an icon CDN.
